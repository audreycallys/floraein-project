# Floraein

*Make every moment bloom.*

Floraein adalah website toko bunga sederhana yang dibuat menggunakan React dan TypeScript. Website ini menampilkan berbagai produk buket bunga dengan fitur keranjang belanja yang interaktif.

Project ini dibuat untuk memenuhi tugas **React Day 1 — Product List**, dengan menerapkan Components, Props, useState, Event Handling, dan Conditional Rendering.

## Fitur

- Menampilkan 8 produk bunga beserta nama, gambar, dan harga.
- Menambahkan dan menghapus produk dari keranjang.
- Menghapus seluruh isi keranjang (Clear All).
- Menampilkan jumlah produk dan total harga keranjang.
- Mengubah tombol Add to Cart menjadi Added setelah produk ditambahkan.
- Tampilan responsif untuk desktop, tablet, dan mobile.

## Teknologi

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Menjalankan Project

Clone repository, lalu install dependencies:

```bash
git clone <URL_REPOSITORY>
cd floraein-website
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka `http://localhost:5173` di browser.

## Catatan

Project ini menggunakan data produk statis dan React State untuk mengelola keranjang belanja, tanpa backend atau database.
